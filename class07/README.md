# YOLO 실험실

수학·정보 융합형 프로그램(고등) **7차시 「한 번만 보고 모두 찾아낸다 — 객체 탐지 모델 YOLO의 수학」** 수업용 웹앱입니다.
PPT의 단계(체험 → ①~⑤ → 심화 IoU·NMS)와 같은 순서, 같은 숫자, 같은 디자인으로 만들었습니다.

- 서버 프로그램·계정·데이터베이스 없이 **정적 웹페이지**로 동작합니다.
- 사진과 웹캠 영상은 **브라우저 안에서만** 처리되고 밖으로 보내지 않습니다.

## 화면 구성

맨 위 메뉴는 두 줄입니다. 첫 줄에서 **원리 · 체험 · 내 사진**을 고르고, 원리를 고르면 둘째 줄에 ①~⑦ 단계가 나옵니다.
모든 화면은 FHD(1920×1080) 한 화면에 맞춰져 있어 스크롤이 생기지 않습니다(창 크기에 맞춰 통째로 확대·축소).
왼쪽은 그림, 오른쪽 위는 조절 도구, 그 아래는 결과입니다. 고른 칸은 **청록 테두리**로, 나머지는 흰 막으로 흐리게 보여 줍니다.

| 메뉴 | PPT | 하는 일 |
|---|---|---|
| 원리 ① 격자 | 6~7쪽 | 격자 크기 바꾸기(3~13), 물체 표 ↔ 중심 칸 계산(①②③) 연결 |
| 원리 ② 존재 확률 | 8쪽 | 칸마다 확률(PPT·학습지의 표), 강조 기준, 시그모이드 함수 실험 |
| 원리 ③ 상자 | 9~10쪽 | 맡은 칸 확대 그림과 (x, y, w, h) 계산, “내가 먼저 계산하기”(입력해서 확인) |
| 원리 ④ 클래스 | 11쪽 | 칸별 클래스 확률 막대 → 최댓값 |
| 원리 ⑤ 신뢰도 | 12쪽 | 존재 확률 × 클래스 확률, 문턱 슬라이더로 상자가 남고 사라짐 |
| 원리 ⑥ IoU (심화) | 14쪽 | 상자 두 개를 끌어 옮기고 크기를 바꾸며 겹친 넓이·합친 넓이·IoU 확인 |
| 원리 ⑦ NMS (심화) | 15쪽 | 후보 상자를 한 단계씩 남기고 지우는 과정, IoU 기준 슬라이더 |
| 체험 | 4쪽 | 사진 올리기(끌어다 놓기 가능)·웹캠·예시 사진으로 실제 탐지, 신뢰도 문턱·NMS 기준, 물체를 누르면 그 상자를 맡은 칸 표시 |
| 내 사진 | — | 직접 찍은 사진이나 예제 사진에 정답 상자 그리기 → 원리 예시로 쓰기, COCO·YOLO·꼭짓점 표기 비교 |

원리 화면의 기본 예시는 수업용 일러스트(횡단보도 장면)이며 7차시 PPT·학습지와 같은 값입니다.
오른쪽 위 ‘예시 사진’ 목록에서 직접 찍은 사진 5장(도로 위 자동차, 양조장 앞, 공항 리무진 버스, 가게 앞, 횡단보도 앞)으로 바꿀 수 있습니다.
사진 예시의 정답 상자와 ⑦ NMS 후보 상자는 실제 YOLOv5n이 낸 결과를 다듬은 것이고, ②·④·⑤의 확률은 정답 상자를 바탕으로 만든 **학습용 예시 값**입니다.
체험의 ‘예시 사진 고르기’에는 11장이 들어 있습니다. 모든 사진의 자동차 번호판과 사람 얼굴은 모자이크했습니다.

## 실행하기

`index.html`을 더블클릭하면 모델을 불러오지 못합니다(브라우저 보안 정책). 아래 중 한 가지로 여세요.

### 1) 학교 서버·GitHub Pages에 올리기 (추천)
폴더 전체를 그대로 올리면 끝입니다. 웹캠을 쓰려면 주소가 **https**여야 합니다.

### 2) 노트북에서 바로 열기
Python이 있으면 이 폴더에서:
```bash
python -m http.server 8000
```
Node.js가 있으면:
```bash
npx serve .
```
그 다음 브라우저에서 `http://localhost:8000` (serve는 표시되는 주소)을 엽니다.
`localhost`에서는 웹캠이 동작합니다. 다른 기기에서 노트북 IP로 접속하면 https가 아니라서 웹캠은 막히고, 사진 올리기는 됩니다.

## 내 사진으로 예시 바꾸기

1. **내 사진**에서 사진을 올리거나(끌어다 놓기 가능) 예제 사진을 고르고, 이름표를 고른 뒤 물체를 끌어 상자를 그립니다.
2. **예시로 저장**하면 원리 화면 오른쪽 위 ‘예시 사진’ 목록에 나타납니다(그 브라우저에만 저장).
3. 모든 학생 기기에서 같은 예시를 쓰려면 **파일로 내보내기**로 받은 `.json` 파일을 `samples/` 폴더에 넣고, `samples/index.json`에 파일 이름을 적습니다.

```json
{ "samples": ["school-crosswalk.json", "bus-stop.json"] }
```

## 사진이 안 열릴 때
아이폰의 HEIC 사진은 브라우저가 열지 못합니다. JPG로 바꿔 올려 주세요. 열 수 없는 파일을 고르면 화면에 이유가 표시됩니다.

## 글꼴
G마켓 산스 Medium이 포함되어 있습니다. `fonts/GmarketSansTTFBold.ttf`(G마켓 무료 글꼴)를 넣으면 제목이 진짜 Bold로 보입니다.

## 사용한 것과 라이선스
- 탐지 모델: **YOLOv5n** (Ultralytics, COCO 80종 사전학습, **AGPL-3.0**) — fp32 ONNX로 변환해 포함. AGPL 조건에 따라 이 웹앱을 배포할 때는 소스를 함께 공개하세요(예: GitHub 공개 저장소).
- 실행: **onnxruntime-web 1.30.0** (MIT, `vendor/ort/`)
- 그림: 수업용 일러스트
- 사진: 개발자(교사)가 직접 촬영한 사진 (번호판·얼굴 모자이크)
- 체험 탭의 사진·영상은 저장되거나 전송되지 않습니다.

## 폴더 구조
```
index.html          화면
css/style.css       디자인 (PPT 색·글꼴)
js/app.js           탭별 동작
js/data.js          원리 탐구 예시 값 (PPT·학습지와 같은 숫자)
js/detector.js      YOLOv5n 실행, IoU, NMS
model/yolov5n.onnx  탐지 모델 (약 8MB)
vendor/ort/         onnxruntime-web
img/                수업용 일러스트
samples/            사진 예시(원리용 5장 *.json + img/), 체험용 사진(try/), index.json
```
