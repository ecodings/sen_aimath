# SenMart 천하제일 알바대회 — 매출을 끌올하라!

4차시 「데이터가 찾아낸 단짝」(연관 분석) 모둠 대항전 웹앱입니다.
모둠마다 SenMart 지점 이름을 정해 입장하고, 영수증 데이터를 분석해 단짝 진열을 정해 겨룹니다.
교사 화면(host.html)을 프로젝터에 띄우면 라운드마다 지점별 순위가 오른쪽에 올라옵니다.

## 1. 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html`, `student.js` | 학생 화면 (입장 · 진열 · 영수증 분석 · 결과 보고서 · 순위) |
| `host.html`, `host.js` | 교사 진행 화면 (참여 코드 · 단계 진행 · 타이머 · 순위판 · 모범답안 · 결과 CSV) |
| `config.js` | **순위판 서버 주소(API_URL)** 를 넣는 곳 |
| `core.js`, `customers.js` | 손님 200명 · 영수증 생성 · 진열 효과 시뮬레이션 · 라운드 설정 |
| `answer.js`, `ans_build.js` | 교사용 모범답안 (`node ans_build.js`로 다시 만들 수 있음) |
| `common.js`, `style.css` | 공통 도구 · 디자인 |
| `apps-script/Code.gs` | 순위판 서버 코드 (구글 Apps Script에 붙여 넣음) |
| `dev/server.js` | 내 컴퓨터에서 테스트할 때만 쓰는 서버 (`node dev/server.js`) |

## 2. GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만들고 이 폴더의 파일을 모두 올립니다.
2. 저장소 **Settings → Pages → Branch: main / (root) → Save**.
3. 1~2분 뒤 주소가 생깁니다.
   - 학생: `https://아이디.github.io/저장소/`
   - 교사: `https://아이디.github.io/저장소/host.html`

## 3. 순위판 서버 만들기 (구글 Apps Script, 처음 한 번)

1. <https://script.google.com> → **새 프로젝트** → `apps-script/Code.gs` 내용을 모두 붙여 넣고 저장.
2. **프로젝트 설정(톱니바퀴) → 스크립트 속성 → 속성 추가**
   `HOST_KEY` = 원하는 교사 코드. GitHub에 Code.gs가 공개되므로 꼭 바꾸세요. 기본값은 `sen2026`.
3. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**. 학생이 로그인 없이 쓰려면 꼭 이 값이어야 합니다.
4. 처음 배포할 때 권한 승인 창이 뜨면 허용합니다.
5. 나온 **웹 앱 URL**(`…/exec`)을 `config.js`의 `API_URL`에 붙여 넣고 GitHub에 다시 올립니다.
6. Code.gs를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 새 버전**으로 다시 배포해야 반영됩니다.

> 학교 Workspace 계정에서 '모든 사용자' 공개가 막혀 있으면 개인 Gmail 계정으로 만드세요.
> 게임 기록은 스크립트 속성에 저장되고, 3일이 지나면 새 게임을 만들 때 자동으로 지워집니다.

## 4. 수업 진행 (교사 화면의 '다음 ▶' 버튼 순서)

| 단계 | 학생이 하는 일 | 시간 예시 |
|---|---|---|
| 입장 | 참여 코드(4자리) + 지점 이름으로 입장. 교사 화면의 QR이나 주소 이용 | 3분 |
| 연습 게임 | 영수증 없이 **감으로** 단짝 1쌍. 연습 영업 1번(순위 제외) | 5분 |
| 1라운드 진열 | 영수증 분석 → 단짝 3쌍 제출. 지표 이름은 아직 숨김 | 10~15분 |
| 1주차 결과 | 순위 발표 → **지지도 · 신뢰도 · 향상도 개념 수업** | 10분 |
| 2라운드 진열 | 지표가 보임 + **계산대 옆 1칸** 추가 | 10분 |
| 2주차 결과 | 순위 변화 확인 | 3분 |
| 3라운드 진열 | **특별 열흘 영업**: 기말고사 + 연말 휴가철 (학원가 학생 3배, 직장인 절반). 영수증 데이터가 '작년 이맘때 열흘'로 바뀜 | 10분 |
| 최종 결과 | 시상대 · 근거 발표 | 5분 |

- 진열 단계에서 타이머(3/5/10/15분)를 켜면 학생 화면에도 남은 시간이 보입니다. 시간이 끝나도 교사가 마감하기 전까지는 제출을 받습니다.
- 학생은 마감 전까지 몇 번이든 다시 제출할 수 있고, 마지막 제출로 점수를 계산합니다. 미제출 지점은 그 라운드 0원입니다.
- 점수 = 진열 효과로 늘어난 매출 × 마진 30%(순이익 증가)이고, 세 라운드를 합산합니다. 같은 라운드에 같은 진열이면 결과도 같습니다.
- 부적절한 지점 이름은 **🛠 지점 관리**에서 숨기거나 이름을 바꿀 수 있습니다.
- 새로고침해도 학생 · 교사 모두 이어서 진행됩니다. 반이 바뀌면 교사 화면에서 **새 게임 만들기**를 누르세요.

## 5. 인터넷 서버 없이 하기 (오프라인 모드)

학교 망에서 Apps Script가 막히는 경우를 위한 예비책입니다.

- 학생: 입장 화면 아래 **'인터넷 순위판 없이 하기'**를 누르고 지점 이름만 입력합니다.
- 교사: 시작 화면에서 **'오프라인 모드'**를 누릅니다. 각 라운드 단계에서 **열쇠 3자리**가 크게 보입니다. 학생은 이 열쇠로 다음 라운드를 엽니다.
- 학생이 진열을 제출하면 바로 결과와 **결과 코드**(예: `2-FKMOIPN`)가 나옵니다. 교사가 **🛠 지점 관리 · 결과 코드 입력**에 넣으면 순위판에 반영됩니다.
- 온라인 모드에서도 기기 문제로 제출하지 못한 지점은 같은 방법으로 넣을 수 있습니다.
